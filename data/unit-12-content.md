# Unit 12: Need / Need to

## Learning Objectives
- Understand when to use "need" as a main verb followed by a noun
- Use "need to" before a verb to express necessity
- Form negatives and questions with "need" and "need to"

## Need / Need to Overview

| Form | Usage |
|------|-------|
| Subject + need + Noun | Expressing need for something |
| Subject + need to + V1 | Expressing necessity to do something |
| Subject + don't/doesn't need + Noun | Not needing something |
| Subject + don't/doesn't need to + V1 | Not necessary to do something |

## Use 1: Need + Noun

"Need" is used as a main verb followed by a noun to express that something is required.

| Example | Burmese |
|---------|---------|
| I need you. | ငါမင်းကို လိုအပ်တယ်။ |
| He needs experience. | သူ အတွေ့အကြုံ လိုတယ်။ |
| You don't need her. | မင်း သူမကို မလိုဘူး။ |
| Do you need money? | မင်း ငွေ လိုလား။ |

## Use 2: Need to + V1

"Need to" is used before a verb infinitive to express that an action is necessary.

| Example | Burmese |
|---------|---------|
| I need to earn money. | ငါပိုက်ဆံရဖို့ လိုတယ်။ |
| She doesn't need to go there. | သူမ အဲဒီကို သွားဖို့ မလိုဘူး။ |
| Do you need to get information? | မင်း အချက်အလက်ရဖို့ လိုလား။ |
| Don't they need to live in Yangon? | သူတို့ ရန်ကုန်မှာ နေဖို့ မလိုဘူး လား။ |
