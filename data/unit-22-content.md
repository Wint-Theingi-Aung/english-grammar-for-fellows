# Unit 22: Too … to ↔ So … that

## Learning Objectives
- Transform "too … to" sentences into "so … that" sentences
- Transform "so … that" sentences into "too … to" sentences
- Understand the relationship between these two structures

## Too … to ↔ So … that

| Form | Pattern |
|------|---------|
| Too … to | too + adjective + to + V1 |
| Too … to (different subject) | too + adjective + for person + to + V1 |
| So … that | so + adjective/adverb + that + result |

## Key Conversions

| Too … to | So … that |
|----------|-----------|
| He is too proud to beg. | He is so proud that he cannot beg. |
| The bag was too heavy for me to lift. | The bag was so heavy that I could not lift it. |
| John is too young to handle this. | John is so young that he cannot handle this. |
