# Unit 24: So … that ↔ Such … that

## Learning Objectives
- Transform "so … that" sentences into "such … that" sentences
- Transform "such … that" sentences into "so … that" sentences
- Understand when to use each structure

## So … that ↔ Such … that

| Form | Pattern |
|------|---------|
| So … that | so + adjective/adverb + that + result |
| Such … that | such + a/an + adjective + noun + that + result |

## Key Conversions

| So … that | Such … that |
|-----------|-------------|
| This book is so good that I can't put it down. | This is such a good book that I can't put it down. |
| The wind is so strong that we cannot go outside. | It is such a strong wind that we cannot go outside. |
| The cake was so tasteless that they bought another one. | It was such a tasteless cake that they bought another one. |
