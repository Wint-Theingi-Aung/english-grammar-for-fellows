# Unit 14: Want / Want to / Want (Obj) to

## Learning Objectives
- Understand when to use "want" with nouns
- Use "want to + V1" to express desires and intentions
- Use "want (object) to + V1" to express what you want someone else to do

## Want Overview

| Form | Usage |
|------|-------|
| Subject + want + Noun | Expressing desire for something |
| Subject + want to + V1 | Expressing desire to do something |
| Subject + want (Obj) to + V1 | Expressing desire for someone else to do something |

## Use 1: Want + Noun

"Want" is used with a noun to express desire for something. It follows the same conjugation rules as regular verbs (want/wants).

| Example | Burmese |
|---------|---------|
| I want you. | ငါမင်းကို အလိုရှိတယ်။ |
| She wants a bigger house. | သူမ ပိုကြီးတဲ့ အိမ် လိုချင်တယ်။ |

## Use 2: Want to + V1

"Want to + V1" is used to express desire to do something. After "do/does/did", use the base form "want".

| Example | Burmese |
|---------|---------|
| He wants to speak English. | သူ အင်္ဂလိပ်စကားပြေးချင်တယ်။ |
| I want to know about your job. | ငါမင်းအလုပ်အကြောင်း သိချင်တယ်။ |
| Do you want to sing a song? | မင်း သီချင်းဆိုချင်လား။ |

## Use 3: Want (Obj) to + V1

"Want (object) to + V1" is used to express what you want someone else to do. The structure is Subject + want + Object + to + V1.

| Example | Burmese |
|---------|---------|
| They want me to take meditation. | သူတို့ ငါ့ကို တရားထိုင်စေချင်တယ်။ |
| My parents want me to work in Japan. | ငါ့မိဘတွေက ငါ့ကို ဂျပန်မှာ အလုပ်လုပ်စေချင်တယ်။ |
