# Unit 42: Three Degrees of Adjectives

## Learning Objectives
- Use the Positive Degree to describe one person or thing
- Use the Comparative Degree to compare two persons or things
- Use the Superlative Degree to compare more than two persons or things

## Positive Degree
When we speak about only one person or thing, we use the Positive Degree. The structure "as + adjective + as" is used to show equality.

| Rule | Example |
|------|---------|
| as + adjective + as | My car is as expensive as his car. |
| as + adjective + as | Sue is as smart as Susan. |
| as + adjective + as | John is as tall as Xin. |

## Comparative Degree
When we compare two persons or two things with each other, we use the Comparative Degree. We use "-er ... than" for short adjectives and "more ... than" for long adjectives. The negative form uses "not as + adjective + as".

| Rule | Example |
|------|---------|
| adjective-er + than | Sue is taller than Susan. |
| not as + adjective + as | Susan is not as tall as Sue. |
| more + adjective + than | Football is more popular than golf. |
| not as + adjective + as | Golf is not as popular as football. |
| adjective-er + than | Xin is brighter than Lie. |
| not as + adjective + as | Lie is not as bright as Xin. |

## Superlative Degree
When we compare more than two persons or things with one another, we use all three Positive, Comparative and Superlative Degrees.

| Rule | Example |
|------|---------|
| the + adjective-est | Leo is the most famous person in this class. |
| more + adjective + than any other | Leo is more famous than any other person in this class. |
| no other + noun + as + adjective + as | No other person in this class is as famous as Leo. |
| the + adjective-est | This flower is the most beautiful one in this garden. |
| more + adjective + than any other | This flower is more beautiful than any other flower in this garden. |
| no other + noun + as + adjective + as | No other flower in this garden is as beautiful as this one. |
