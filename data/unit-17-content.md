# Unit 17: There is / There are

## Learning Objectives
- Use "there is" and "there are" to talk about things that exist
- Use "there isn't" and "there aren't" to say things don't exist
- Form questions with "Is there" and "Are there"
- Ask about quantities with "How many"

## There is / There are (Present)

| Form | Usage |
|------|-------|
| There is/There's + singular noun | Talk about one thing |
| There isn't + singular noun | Say one thing doesn't exist |
| There is + uncountable noun | Talk about uncountable things |
| There isn't + uncountable noun | Say uncountable things don't exist |
| There are + plural noun | Talk about many things |
| There aren't + plural noun | Say many things don't exist |

## Key Rules

| Rule | Example | Burmese |
|------|---------|---------|
| There is + singular noun | There is a book on the desk. | စာအုပ်တစ်အုပ် ပွင့်ပေါ်မှာ ရှိတယ်။ |
| There isn't + singular noun | There isn't a book on the desk. | စာအုပ်တစ်အုပ် ပွင့်ပေါ်မှာ မရှိဘူး။ |
| Is there + singular noun? | Is there a dog in the supermarket? | စူပါမားကက်ထဲမှာ ခွေးတစ်ကောင် ရှိလား။ |
| There is + uncountable noun | There is some milk in the fridge. | ရေခဲသတ္တုထဲမှာ နွားနို့ အနည်းငယ်ရှိတယ်။ |
| There isn't any + uncountable | There isn't any juice in the fridge. | ရေခဲသတ္တုထဲမှာ အချိရည် မရှိဘူး။ |
| There are + plural noun | There are books on the desk. | စာအုပ်တွေ ပွင့်ပေါ်မှာ ရှိတယ်။ |
| There aren't + plural noun | There aren't any people at the party. | ပါတီမှာ လူတွေ မရှိကြဘူး။ |
| How many + plural + are there? | How many students are there in your class? | မင်းတို့ အတန်းထဲမှာ ကျောင်းသား ဘယ်နှစ်ယောက် ရှိလဲ။ |
