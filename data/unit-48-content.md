# Unit 48: Translation (From Myanmar to English)

## Learning Objectives
- Learn to translate Myanmar sentences into English
- Understand sentence structure and phrase divisions
- Practice translating complex sentences with multiple clauses

## Translation Examples

### Example 1
**Myanmar:**
လူတိုင်းတိုင်း / ဝါသနာကိုယ်စီ / ရှိကြသည်။ // အချို့အကျင့်များသည် / အကျိုးပြုသည် ဝါသနာဖြစ် / လျှင်ကျန်၊ အရက်သောက်ခြင်း တို့သည် / ဘဝကိုပျက်စီးစေသည်။ // အကျင့်ပျက်များ ပပျောက်ရန် / အကျင်းကောင်းများ / ပြုလုပ်ရအတွက် / အမြဲ ဆောင်ရွက်သင့်ပါသည်။ //

**English:**
Everybody / has / his or her own hobby. // Although some habits are beneficial, / other / brings about / bad effects. // Reading and playing sports / are the hobbies (which are) beneficial / to us and our surroundings and / gambling and drinking / spoil / life. // Measures should always be taken / for wiping out bad habits and / making good habits. //

### Example 5
**Myanmar:**

### Example 6
**Myanmar:**

### Example 12
**Myanmar:**
ပရဟိတစိတ်ဓာတ်ဟာသည် / အများအကျိုးသယ်ပိုးကြွေးမြွက်သည့် / စိတ်ဓာတ်ဖြစ်သည်။ // လူတိုင်းလူတိုင်းသည် / ပရဟိတစိတ်ဓာတ်မှုမွေး / အများအကျိုးကို သယ်ပိုး သင့်ကြောင်း သင်ကြားသည်။ // ပရဟိတစိတ်ဓာတ်များ ကိုယ်စားပြုငွေ ပမာဏရင်သန်ထွန်းကားလျှက်လျှင် / ပရဟိတ လုပ်ငန်းလုပ်ကိုင်သည့်အတွင်း / ကျေးဇူးအကျိုး သယ်ပိုး က / တန်ဖိုးများခံစားရကာ / လောကကြီးသည်လည်း သယ်ဝတ္ထုပေါက်ခင်တည်ဟု သိ / အလွန်ရှင်းလင်းက / ပိုမိုရရှိပိုင်ဆိုင်မည်မှာ / မလွှဲဧကန်ပင် ဖြစ်ပါသည်။ //

**English:**
Altruism / is the spirit / to serve the interest of others. // Everybody / must have / altruism and / should serve / the interests of others. If everybody has altruism, / altruists / will enjoy / the benefits. // It is true that / the world / will be pleasant and beautiful. //

### Example 13
**Myanmar:**
မြန်မာလူ့ ဘာသာအဖွဲ့အစည်းတွင် / မြန်မာအမျိုးသမီးများသည် / ဓာတ် ရာစဉ်အလာ ဓလေ့ထုံးတမ်းများအရ / ယဉ်ကျောသမ်းမှု့ကြောင်း သည်။ // ယဉ်ကျောအမျိုးအကျင့်၊ ဘာသာတရားကိုင်းမြှောက်မှု၊ စာရိတ္တတည်း ကိုက်ညီတရား / ထွန်းသမ်းခင်တို့တွင် / စံတင်ရမည်ဖြစ်သည်။ // ပင်ကိုဗဇတ ညှ ညာသမ်းမှု့ခင်၊ အရက်သောက်၊ ဣဋ္ဌက ခေါင်းစဉ်စသည် / မြန်မာအမျိုးသမီးများ၏ / မူ ရပ်ထ ခေါ်ချက်များ / ရေ ဘေး ဘေး မွှာလက်ထက်ကပင် / ရှင်းပျဖြစ်သည်။ // ယနေ့ မှ ဆက်သစ်လမ်းသည် / ရေ အစဉ်အလာရ သိ မြန်မာအမျိုးသမီးများ၏ ဂုဏ်ရည်ကို / မပျက်ပျက်ရန် / ဆက်လက်ထွန်းသမ်းသည့် / ကြံရမည်ဖြစ်သည်။ //

**English:**
In Myanmar Society, / Myanmar women / are polite and gentle / in accordance with traditional customs. // They / will be an example / in preserving / polite manner, devoutness, character and morals. // Myanmar women's / inborn particular / such as inborn politeness, modesty and solemnity / have been existing / since the time of forefathers. // New generation of today / must continue to uphold / the prestige of Myanmar women / with traditions / not to lose. //

### Example 14
**Myanmar:**
ပညာရေးမြှင့်တင်မှုအစအစများအရ / နိုင်ငံတကာအဆင့်မီပညာရပ်များ၊ အတတ်ပညာနှင့် နည်းပညာများ၊ ကွန်ပျူတာနည်းပညာများနှင့် သတင်းအချက်အလက်ဆိုင်ရာ နည်းပညာများ စသည် / ခေတ်မှီတိုးတက်သည် ပညာရပ်ဆိုင်ရာ တိုးတက်ဖြစ်ထွန်းမှုများသည် / နိုင်ငံတကာနှင့် ဆက်စပ်ပေါင်းသက်သက် / ကျောင်းသံသို့ ကျောင်းသားတစ်ယောက်ချင်စီ၏ / စိတ်ဓာတ်ရရှိပိုင်တင် / အခြေခံကောင်းစရန် / မွှေ ချစ်စိတ်ဓာတ်၊ ပြည်ထောင်စုစိတ်ဓာတ်၊ စည်းကမ်း၊ စာရိတ္တတည်းနှင့် ပညာသုံးနတ္တိ စသည် / စိတ်ဓာတ်ပိုင်းဆိုင်ရာ ဖွံ့ဖြိုးမှုဖြစ်ထွန်းအောင် / နိုင်ငံ တိုးက / စီမံ ပေးငွေခံသည်။ //

**English:**
According to the Education Promotion Programme, / modern educated developments / such as international standard education, skills and technologies, computer technology and information technologies / can be connected / with the world. // Similarly, / the state / could make arrangements / to bring about spiritual developments / such as patriotism, Union Spirit, discipline, character and civic duty / to strengthen / the mindset / of each student. //
