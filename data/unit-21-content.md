# Unit 21: So … that

## Learning Objectives
- Use "so + adjective/adverb + that + result" to show cause and effect
- Combine two sentences into one using "so … that"

## So … that

| Form | Usage |
|------|-------|
| so + adjective/adverb + that + result | Show cause and effect |

## Key Rules

| Rule | Example | Burmese |
|------|---------|---------|
| so + adj + that + result | The water is so salty that I cannot drink it. | ရေက အရမ်းငန်လို့ ငါမသောက်နိုင်ဘူး။ |
| so + adv + that + result | We arrived so late that we could not have dinner. | ငါတို့ ရောက်တာ တော်တော်နက်ကာခဲ့လို့ ညစာမစားနိုင်တာဘူး။ |
